# usage-bar

Claude Code 입력창 바로 위에 사용량을 색 막대로 보여주는 플러그인입니다.

```
ctx ███░░░░░░░ 11% │ 5h ████░░░░░░ 37% (16:10) │ 7d █░░░░░░░░░ 14% (12:00) │ $1.48
```

- **ctx**: 현재 대화의 컨텍스트 창 사용률
- **5h / 7d**: 구독 사용량 한도 소진율 (괄호는 초기화 시각)
- **$**: 이번 세션 사용량을 API 정가로 환산한 추정 금액 (구독이면 청구되지 않음)
- 색: 50% 미만 초록, 80% 미만 노랑, 그 이상 빨강
- 답변이 끝날 때마다 갱신됩니다.

## 설치

Claude Code 프롬프트에서:

```
/plugin install usage-bar --marketplace HaechanJ/claude-usage-bar
```

마켓플레이스 추가를 묻으면 `y`, 이어서 설치 범위(scope)를 고르세요.
